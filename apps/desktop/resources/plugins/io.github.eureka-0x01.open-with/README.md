# Open With

Open With 是一个 PI-Desktop 插件，用于通过资源管理器、代码编辑器或其他应用打开当前项目目录。在聊天输入框底栏即可完成操作，方便从对话切换到本地开发工具。

当前版本：**0.1.0**。需要 **PI-Desktop 0.9.0 或更高版本**。

## 功能

- 一键使用当前选中的应用打开项目目录。
- 内置系统文件管理器，首次使用时默认选中。
- 支持添加、编辑和删除自定义打开方式，例如 VS Code、IntelliJ IDEA。
- 自动保存应用列表和选中状态，下次启动后继续使用。
- 在 Windows 上尝试提取程序图标，提取失败时显示默认图标。
- 界面跟随 PI-Desktop 的明暗主题。

## 安装

1. 下载或克隆本仓库到本地。
2. 打开 PI-Desktop 的插件页，选择“从本地目录加载”，选中项目文件夹。
3. 按宿主提示授权 `renderer.extension`，用于显示按钮和应用管理界面。
4. 加载完成后，聊天输入框底栏左侧会出现打开方式按钮。

## 使用

先在 PI-Desktop 中打开一个项目，再点击按钮主区域，即可使用当前选中的应用打开该项目目录。

点击按钮右侧的 **▾** 可以查看应用列表。点击列表中的应用只会切换选中项；需要打开目录时，再点击主按钮。主按钮会显示选中应用的名称和图标。

### 添加打开方式

1. 点击 **▾ → 添加打开方式**。
2. 填写应用名称，例如 `VS Code`。
3. 粘贴程序文件的完整路径，例如 `C:\Program Files\Microsoft VS Code\Code.exe`。
4. 保存后，在列表中选中该应用，再点击主按钮打开项目目录。

Windows 上的程序路径需要以 `.exe` 结尾，请填写已安装程序的实际路径。插件会清理粘贴路径时带入的常见隐藏字符和首尾引号。当前通过粘贴路径添加应用，不提供文件浏览选择。

插件会将当前项目目录作为参数传给程序，因此所选程序需要支持通过命令行参数打开文件夹。

### 管理打开方式

将鼠标移到自定义应用上，可以编辑名称、程序路径或删除该条目。最多支持 32 个自定义应用，名称最多 40 个字符。

内置文件管理器不可编辑或删除。删除当前选中的自定义应用后，会自动切回内置文件管理器。

## 平台与隐私

内置文件管理器按系统调用 Windows 资源管理器、macOS Finder 或 Linux 默认文件管理器。自定义应用的添加说明以 Windows `.exe` 程序为主。

应用配置保存在 PI-Desktop 的插件设置中。插件不联网、不读取剪贴板；在 Windows 上保存自定义应用时，会调用系统 PowerShell 读取程序图标。点击主按钮时，会启动选中的程序并传入当前项目目录。

`renderer.extension` 允许插件界面在宿主主窗口中运行，需要明确授权。外部程序按其自身权限运行，其行为由所选程序决定。
