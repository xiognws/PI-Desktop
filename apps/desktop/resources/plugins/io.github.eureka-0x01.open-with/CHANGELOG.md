# 更新日志

## 0.1.0 — 2026-10-18

首次正式发布。

- 在 PI-Desktop 输入框底栏提供打开当前项目目录的按钮。
- 内置系统文件管理器，支持添加、编辑和删除自定义打开方式。
- 应用列表只切换选中项，点击主按钮才打开目录。
- 持久保存应用列表和选中状态，删除选中应用后自动回落内置文件管理器。
- 支持 Windows exe 路径清理、扩展名与盘符绝对路径存在性校验，以及程序图标提取。
- 界面跟随宿主明暗主题。
- 将可选图标提取的等待时间限制为 1 秒，超时使用默认图标，为宿主调用时限预留时间。

此前的 0.6.0、0.7.0 属于开发阶段编号；首次正式发布统一使用 0.1.0，Git 历史保留不变。
