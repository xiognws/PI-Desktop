# 座舱 HMI 自动化等待策略

Tags: 座舱, HMI, 蓝牙, 等待, 超时, 自动化

Source: standard 座舱自动化测试规范 v2

Id: hmi-0001
Collection: cockpit-hmi

禁止固定 sleep。所有等待必须是条件等待 + 上限：
  元素出现    ≤ 3000 ms，轮询 100 ms
  列表加载    ≤ 3000 ms（蓝牙设备列表实测 1.2–2.4 s）
  页面转场    ≤ 1500 ms
  蓝牙配对    ≤ 20000 ms（配对码交互不计入）

失败时输出：当前页面截图、可见元素名列表、等待了多久。只报「元素未找到」的用例在诊断阶段无法归类。

旋转/翻转或分辨率变化后必须重新获取元素坐标，缓存的坐标在布局变化后失效。
